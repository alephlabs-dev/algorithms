# Translating the app

English lives at `/`, Spanish under `/es` (see `docs/adr/0001-language-in-url-prefix-typed-dictionaries.md`). A page load is in one language for its whole life, so text is picked once, when its module loads.

## How

Put the English and the Spanish side by side with `localized` from `src/i18n.ts`, next to where the text is used:

```ts
import { localized } from "@/i18n";

const text = localized({
  en: { play: "Play", swap: (a: number, b: number) => `Swap ${a} and ${b}.` },
  es: { play: "Reproducir", swap: (a, b) => `Intercambia ${a} y ${b}.` },
});
```

- The Spanish must have the same shape as the English, so a missing translation fails `make check`.
- Sentences with numbers are functions. Handle plurals inside them (`n === 1 ? "elemento" : "elementos"`).
- The English text must stay exactly as it was: unit and e2e tests read it.
- When a module is translated, add it to `TRANSLATED` in `src/routes.ts`, so its `/es` pages get indexed.
- Don't translate pseudocode, URLs or query-string values.
- A descriptive name needs an article inside a sentence ("Cómo funciona **la** búsqueda en anchura"). Give it a `named` entry next to its `title` and use `named` mid-sentence; proper names (Quick Sort) don't need one.
- Colors agree with what they color: "barras moradas", "celdas moradas", but "nodos morados". Only feminine plurals can reuse `colorNames` in `src/modules/tours.tsx`.
- Check every Spanish screen at 393, 834 and 1280px: Spanish runs longer, and pills, the top-bar summary and one-line overlays are where it spills. Shorten the Spanish there rather than changing the layout.

## Spanish style

Neutral Spanish, addressing the learner as *tú*: "Presiona play", "Elige un algoritmo", "Toca una barra". No *vos*, no *vosotros*, no regionalisms. Short sentences, like the English.

Algorithms keep their usual English name (Quick Sort, Merge Sort, Heap Sort, Radix Sort, Dijkstra, A\*, Prim, Kruskal). Descriptive names are translated: "Búsqueda en anchura (BFS)", "Búsqueda en profundidad (DFS)", "Árbol binario de búsqueda", "Tabla hash con encadenamiento", "Distancia de edición".
